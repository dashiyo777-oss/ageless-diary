# エイジレス・ダイアリー（Ageless Diary）― 若さ維持の実践情報サイト

Threads（アンチエイジング用アカウント）から誘導する、**独立ブランドの情報サイト**一式です。
政治・経済の発信（note／既存ポートフォリオ）とは **完全に別のリポジトリ・別サイト** として運用します。

**コンセプト**：シニア世代が、お金をかけずに自分でできる「若さ維持の方法」を、
世の中の**研究・統計・公的情報にもとづいて**正直にまとめる。
（例：ほうれい線・目の下のたるみの顔の運動／姿勢の矯正／シミと皮膚科の使い方／毎日の習慣）

```
Threads投稿（今日のひとつのコツ） → リプ欄に"サイト記事へのリンク" → 記事（＝価値の本体） →〔審査通過後〕関連する時だけ楽天リンク
                                                                     ↑ 検索でも読まれ続ける"資産"
```

## いまの段階：楽天リンクは「オフ」

楽天アフィリエイトは**フォロワーがある程度いないと審査に通りにくい**ため、まずは
**有益な情報だけで信頼とフォロワーを育てる**フェーズにしています。
そのため、テンプレ・見本記事の楽天ブロックは**コメントアウトして非表示**にしてあります（削除ではないので、審査通過後すぐ戻せます）。

- **フェーズ1（いま）**：良い記事を出す＋Threadsでコツを発信 → **フォロワー100人**を目指す（＝先生の目標）
- **フェーズ2（審査通過後）**：楽天ブロックを有効化して、関連する記事にPR明記で楽天リンクを追加

> 💰 **将来の目玉候補**：運営者が**約30年飲み続けているサプリ**は、"本物の長期体験"という何より強い一次情報です。
> 審査通過後、薬機法に配慮して（効能はうたわず、続けている理由・飲み方・選び方などの体験ベースで）
> レビュー記事にすると、信頼を保ったまま収益の柱にできます。→ フェーズ2の最初の一本におすすめ。

## セットアップ手順

### 1. ブランド名を変える（任意）
仮名は「**エイジレス・ダイアリー / AGELESS DIARY**」。変えたい場合は、各 `.html` の以下を一括置換：
- `エイジレス・ダイアリー` → あなたのサイト名
- `AGELESS DIARY` → 英字表記
- 絵文字マーク `🌿` → 好きなもの
- `（ペンネーム）` → 実際のペンネーム（※**政治側の実名は使わない**＝分離）

> ⚠️ 政治側の名前・ハンドル・ドメインを想起させる語は入れないこと。分離が崩れます。

### 2. 新しいGitHubリポジトリを作って公開する
このフォルダごと、**新規リポジトリ**（例：`ageless-diary`）に入れます。ターミナルで：

```bash
cd ageless-diary
git init
git add .
git commit -m "init: ageless diary site"
# GitHubで空のリポジトリ ageless-diary を作成してから ↓
git remote add origin https://github.com/＜あなたのユーザー名＞/ageless-diary.git
git branch -M main
git push -u origin main
```

- 中身を整えてから公開したい場合は、GitHubでリポジトリを **Private** で作成 → 準備できたら公開に切替。
- **GitHub Pages**：リポジトリの Settings → Pages → Branch を `main` / `(root)` に設定 → 数分で
  `https://＜ユーザー名＞.github.io/ageless-diary/` で公開されます。

> 独自ドメインを使うと分離がさらにクリーンです（Settings → Pages → Custom domain）。

### 3. 記事を書く（1記事＝1ファイル）
1. `method-template.html` を複製し、`houreisen-exercise.html` のように分かる名前にリネーム。
2. `【　】` の箇所を、**根拠（出典つき）と手順**で埋める。見本は `houreisen-exercise.html` を参照。
3. 各ブロックの役割：
   - `.evidence`（研究でわかっていること）… 大げさにせず、限界・個人差も正直に。
   - `.steps`（やり方）… 番号つきの手順。写真や図があるとなお良い。
   - `.caution`（やりすぎ注意・受診の目安）… **体に関わる記事では必ず入れる**。「治す」と約束しない。
   - `.source`（参考にした情報）… 出典を明記。**これが"こたつ記事でない"証拠＝信頼の源**。
4. **楽天リンクは、いまはオフ**（審査前のため）。テンプレ内にコメントアウトで残してあるので、
   審査に通ったら下の「§5 審査に通ったら」の手順で有効化します。
5. `index.html` の「最新の記事」に、その記事へのカードを1つ追加（ひな形コメントあり）。

## 4. Threads運用の型（先生の全体像に沿った進め方）

先生の教えの通り、**リンクは本文ではなくリプ欄（返信）に貼る**のが鉄則です（本文に貼るとリーチが落ちるため）。

```
① 価値ある投稿をする（例：「ほうれい線、1日3分でできる顔の運動」の"さわり"を本文で）
② リプ欄（自分の返信）に、続き＝サイト記事のリンクを貼る   ← 本文には貼らない！
③ これを繰り返し、まずはフォロワー100人を目指す
```

- **いま（審査前）**：リプ欄に貼るのは「**サイト記事へのリンク**」。記事が価値の本体になり、フォローと信頼が貯まる。
- **審査通過後**：投稿の内容に応じて、リプ欄に置くものを使い分け。
  - 方法・ノウハウ系の投稿 → リプ欄に**サイト記事リンク**（記事内に楽天リンク）
  - 特定商品を薦める投稿（例：30年飲んでいるサプリ）→ リプ欄に**楽天リンクを直貼り**（先生のシンプル型）／またはサイト記事リンク

> リプ欄テキストの例（コピペ用）：
> 「続きと詳しいやり方はこちらにまとめました🌿 → （サイト記事のURL）」

---

## 5. 審査に通ったら（楽天リンクの有効化）

1. `method-template.html`・各記事内の `▼▼ 楽天リンク … ▲▲` のコメント（`<!-- -->`）を外して表示に戻す。
2. `href="【 … 】"` に、`rakuten-threads.html`（政治側ポートフォリオ同梱の自分用ツール）で
   商品検索 →「🔗 リンクをコピー」で得た `affiliateUrl` を貼る。
3. 各ページ footer の「一部にアフィリエイト広告（楽天アフィリエイト等）を含みます。」の一文を戻す
   （`method-template.html` の footer にコメントで残してあります）。
4. **最初の一本は「30年飲んでいるサプリ」レビュー**がおすすめ（本物の長期体験＝最強の一次情報）。
   薬機法に注意し、効能はうたわず「続けている理由・飲み方・選び方」など体験ベースで。

## ぜったいに守るルール（このサイトの信頼＝資産の源）

- **大げさに言わない**：「必ず若返る」「シミが消える」等の断定はしない。わかっている範囲・限界・個人差を正直に。
- **出典を示す**：研究・統計・公的機関の情報など、実際に確認した一次情報を `.source` に明記（＝こたつ記事にしない）。
- **安全第一**：体に関わる方法には**やりすぎ注意・受診の目安**を必ず添える。困った時は医師へ、と誘導。
  健康・医療の情報は誇大表現・断定を避ける（医療広告・景表法の観点）。
- **薬機法**：化粧品・サプリを紹介する時は「治る・若返る・シミが消える」等の効能をうたわない。使用感・事実まで。
- **景表法（ステマ規制）**：アフィリを含む部分は **「PR」明記が必須**。テンプレの `.pr-banner` を消さない。
- 詳しい運用の考え方は、政治側ポートフォリオ同梱の `rakuten-threads-setup.md`（運用ガイド）を参照。

## デザインを変えたい時
`assets/style.css` の先頭 `:root{ … }` にある色変数（`--sage` など）を書き換えるだけで全ページの色が変わります。
和風にしたい・もっと可愛くしたい等の要望があれば、変数の値だけ調整すればOKです。
