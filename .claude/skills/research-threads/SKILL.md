# ①リサーチ（先生のワークフローの起点）

目的：「エイジレス・ダイアリー（@yoshida.ageless）」のネタ源を集める。まず `content/brand-voice.md` を読み、ペルソナ（70歳男性・よしだ）とルールを守ること。

## リサーチの条件（ここが命）
抽象的な調査はNG。**人間がやるような具体的な条件**で調べる。
- 対象ジャンル：シニア/アラフィフの「お金をかけない若さ維持」＝表情エクササイズ・姿勢・シミと皮膚科・睡眠・日焼け・食事・サプリ体験
- 集めるもの：
  1. **伸びているネタ**（どんな悩み・切り口が反応されているか）
  2. **伸びている投稿の"型"**（1行目のフック／箇条書き／最後の問いかけ 等の構成）
  3. **自分のジャンルで使える知識**（研究・統計・公的情報。※必ず一次情報の出典をメモ）

## 手順
1. `WebSearch` で上記テーマの最新トレンド・よくある悩み・話題の方法を調べる。
2. 参考になりそうな記事・公的情報は `WebFetch` で中身を確認し、**出典（媒体名・URL・年）**を控える。
3. 見つけた「読者のリアルな悩み・質問」を書き出す（次のネタになる）。
4. 結果を `content/research.md` に追記（日付つき）。フォーマット：
   ```
   ## YYYY-MM-DD リサーチ
   ### 伸びてるネタ / 悩み
   - …
   ### 使える投稿の型（フック例）
   - …
   ### 使える知識（出典つき）
   - 〜という報告（媒体名, 年, URL）※限界・個人差もメモ
   ### 読者の質問・疑問
   - …
   ```

## 守ること
- **アイデアを得るためのリサーチであり、他人の投稿の丸写しはしない**（こたつ記事禁止）。
- 数字・研究に触れる時は必ず出典と限界をセットで残す（後で誇張表現を避けるため）。
- 効能をうたう表現は拾っても、そのまま使わない（薬機法）。
