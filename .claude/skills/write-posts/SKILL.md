# ③ライター（ワークフローの肝：投稿を書く）

目的：**コピペで投稿できるドラフト**を作る。作業前に必ず読む：
1. `content/brand-voice.md`（ペルソナ・絶対ルール・フォーマット）
2. `content/next-topics.md`（アナリストが決めた次のテーマ。無ければ既定テーマから選ぶ）
3. `content/research.md`（あれば。フック例・出典つき知識）

## 書き方（brand-voice.md を厳守）
- 語り手は**70歳男性・よしだ本人**。実体験、または「研究では〜と報告」の正直な情報提供のみ。
- 大げさに言わない／効能をうたわない（薬機法）。体の話は「やりすぎ注意・不安なら医師へ」。
- 1投稿1テーマ、約120〜400字、平易な言葉、絵文字控えめ。**最後は必ず質問で締める**。
- リンクは本文に貼らない。**記事がある回だけ「リプ欄」テキストを添える**（現状は「ほうれい線」記事のみ）。楽天リンクは審査前なので入れない。

## 本数
指定がなければ**7本**（＝1週間分）。テーマは散らす。

## 出力
`content/post-queue.md` に追記。1本ずつこの形式：
```
### [ ] 投稿案 N｜テーマ
本文：
（本文）

リプ欄：（記事がある回のみ。無ければ「なし」）
（リプ欄テキスト＋記事URL）
---
```
先頭の `[ ]` は未投稿の印。投稿したら `[x]` に変え、日時を追記して post-history 代わりにする。

## 最後に
「今週のひとこと：投稿は1日1本・同じ時間帯・最後に質問。まず同系アカウントに毎日10件いいね/コメントを」と運用リマインドを1行添える。
