# 知識メモ 目次（knowledge INDEX）

YouTube等の素材を「整理して蓄える」棚。素材が届くたびに、下の一覧に1行追加し、`knowledge-◯◯.md`として保存していく。

## 運用ルール（毎回これを守る）
1. 素材は**二次情報**（動画/本の要約）として扱う。鵜呑みにしない。※話者が第一人者の"本人ソース"は信頼度高め。
2. 必ず**事実チェック（一次情報で裏取り）**。「確実／最強／必ず効く」等の断定は"盛り"として外す。
3. 保存フォーマット：出典・要約・**事実チェック（◎堅い/△盛り注意/×根拠薄い）**・よしだ活用メモ（薬機法/景表法・投稿ネタ・記事化案）。
4. 薬機法/景表法：食品・化粧品は「効く/治る/若返る」を書かない。運動等は製品でないが、断定は避け「研究で報告されている＋個人の体験＋個人差」に。医療（ホルモン補充・検査・数値・病名）は「医師へ／健診で確認」に留める。研究者が関与する商品（サプリ等）は"効く"文脈で使わない（利益相反）。
5. 素材は1本ずつ処理（事実チェックに時間をかけ、取りこぼさない）。
